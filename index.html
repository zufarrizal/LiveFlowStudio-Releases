GOOD TO KNOW

Questions before download?

Here are the practical details most users need before getting started.

Ask Store Support
Does LiveFlow Studio work without an active account?

No. An active LiveFlow Studio account and an authorized TikTok assignment are required to use the application.

What is the difference between installer and portable?

The installer adds LiveFlow Studio to Windows normally. The portable ZIP can be extracted into a dedicated folder and run without installation.

Does exported JSON contain my audio files?

No. Audio files are not embedded in exported JSON. During import, LiveFlow Studio shows a preflight and can restore missing MyInstants audio from its original source after approval.

Does the Shop process payments inside the app?

No. The in-app Shop is a product catalog. Checkout, payment, delivery, and Store Support continue through the official Zal Digital Telegram bot.

Why can Windows show a security warning?

The current installer does not use a commercial code-signing certificate, so Windows may show “Unknown Publisher” or SmartScreen. Verify the repository source and SHA-256 before installation.
